# hatchbox maintenance

turn maintenance mode on and off

* [`hatchbox maintenance`](#hatchbox-maintenance)
* [`hatchbox maintenance:off`](#hatchbox-maintenanceoff)
* [`hatchbox maintenance:on`](#hatchbox-maintenanceon)

## hatchbox maintenance

Display the current maintenance status of an app.

```
Usage: hatchbox maintenance

Flags:
  -a, --app APP        app to run command against
  -r, --remote REMOTE  remote saved for this repo in ~/.hatchbox to run command against
```

## hatchbox maintenance:off

Take the app out of maintenance mode.

```
Usage: hatchbox maintenance:off

Flags:
  -a, --app APP        app to run command against
  -r, --remote REMOTE  remote saved for this repo in ~/.hatchbox to run command against
```

## hatchbox maintenance:on

Put the app into maintenance mode.

```
Usage: hatchbox maintenance:on

Flags:
  -a, --app APP        app to run command against
  -r, --remote REMOTE  remote saved for this repo in ~/.hatchbox to run command against
```
